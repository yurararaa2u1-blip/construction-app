## 1. 概要・目的

全8画面のレイアウト・遷移・UI要素を定義する。デザイン（色・フォント）は後工程で決定し、本書では「何をどこに配置するか」に集中する。

## 3. 共通UIコンポーネント

- **ナビゲーションバー（上部）**: ロゴ・通知ベル・ユーザーアバターを全画面に表示
- **サイドバー（左側）**: ダッシュボード・現場一覧・工程管理・通知・ユーザー管理へのリンク
- **ステータスバッジ**: 進行中（緑）・遅延中（赤）・計画中（青）・完了（グレー）
- **進捗バー**: 0〜100%を視覚的に表示。遅延中は赤色で表示
- **モーダル**: 現場登録・編集などの短いフォームはモーダルで表示

## 4. 各画面の要点

### S-01 ログイン画面
- タイトル「アカウントにログイン」、メールアドレス入力、パスワード入力、ログインボタン。
- 認証成功でダッシュボード（S-02）へ遷移。

### S-02 ダッシュボード
- サマリーカード：現場数 / 遅延中 / 今週完了 / 平均進捗。
- 現場一覧テーブル：現場名・担当者・工期終了・進捗・ステータス。

### S-03 現場一覧
- 「現場を追加」ボタン、現場名・担当者での検索。
- 現場カード：現場名・担当者・工期終了日・進捗バー・ステータスバッジ。

### S-04 工程管理（ガントチャート）※最重要画面
- 現場名・ステータス・「工程追加」ボタン。
- 月単位の時間軸に各工程（基礎工事・鉄骨建方・外壁工事・内装工事・竣工検査など）をバー表示。
- 各工程にステータス（完了/進行中/遅延中/未着工）と進捗率。
- 遅延工程はハイライト表示し、「○○工事が予定より14日遅延しています。担当者へメール通知済み。」のような遅延メッセージを表示。
- 選択中の工程の進捗率を更新するUI（→ `PATCH /api/tasks/:taskId` を呼ぶ）。

### S-05 ユーザー管理（管理者専用）
- サマリー：総ユーザー数 / 管理者 / 現場監督 / 閲覧のみ。
- 「ユーザーを招待」ボタン。
- ユーザーテーブル：氏名・メールアドレス・役割・登録日・操作（役割変更）。
- adminロール以外がアクセスすると403エラー画面。

### S-06 現場詳細
- 現場名・ステータス・「編集」「工程を見る」ボタン。
- タブUI：基本情報 / 工程 / メンバー。
- 基本情報：現場住所・工期・全体進捗。メンバー：氏名・メール・役割。

### S-07 通知一覧
- 「未読 N件 / 全 M件」「すべて既読にする」ボタン。
- フィルタタブ：すべて / 遅延アラート / リマインダー / 未読のみ。
- 通知アイテム：種別・現場名・メッセージ・日時。クリックで既読化＆対象工程へ遷移。

### S-08 現場登録・編集フォーム（モーダル）
- 入力項目：現場名（必須）・現場住所・工期（開始日〜終了日、必須）・ステータス（必須）・担当メンバー追加。
- 「キャンセル」「登録する」ボタン。「登録する」で `POST /api/projects` を呼ぶ。

## 5. 画面遷移ルール

| 操作・条件 | 遷移 |
| --- | --- |
| ログイン成功 | S-01 → S-02 ダッシュボード |
| 現場カードをクリック | S-03 → S-06 現場詳細 |
| 「工程を見る」ボタン | S-06 → S-04 工程管理 |
| 通知アイテムをクリック | S-07 → S-04 工程管理（対象工程） |
| 「現場を追加」ボタン | S-03上に S-08 モーダルを表示 |
| 未認証でアクセス | すべての画面 → S-01 ログインへリダイレクト |
| ユーザー管理へのアクセス | adminロール以外 → 403エラー画面 |
