## 1. 概要・目的

本アプリのシステムアーキテクチャを定義する。要件定義書（v1.1）で定めた機能要件・非機能要件を実現するため、システム構成・技術スタック・データの流れを明確にし、開発チーム全員が共通認識を持つことを目的とする。

## 2. システム構成（3層アーキテクチャ）

現代のWebアプリケーション標準である「3層アーキテクチャ（スリーティア）」を採用する。各層を分離することで、保守性・拡張性・セキュリティを確保する。

| 層 | 役割 | 使用技術 |
| --- | --- | --- |
| プレゼンテーション層（フロントエンド） | ユーザーが直接見て操作する画面。ブラウザ・スマホ上で動作する。 | React + Tailwind CSS |
| アプリケーション層（バックエンド） | ビジネスロジック・認証・APIの処理を担当するサーバー。 | Node.js + Express |
| データ層（データベース） | 工程・ユーザー・現場データを永続的に保存・管理する。 | PostgreSQL（AWS RDS） |

## 3. インフラ構成（AWS）

インフラはAWS（Amazon Web Services）を採用する。マネージドサービスを活用し、運用コストを削減して可用性99%以上（非機能要件NF-04）を実現する。

| サービス | 正式名称 | 役割 | 料金目安 |
| --- | --- | --- | --- |
| EC2 | Elastic Compute Cloud | Node.jsサーバーが動く仮想マシン | 月1,000〜5,000円程度 |
| RDS | Relational Database Service | PostgreSQLのマネージドDB | 月2,000〜8,000円程度 |
| S3 | Simple Storage Service | Reactビルドファイル・画像の保存 | 月数百円程度 |
| CloudFront | CDN（コンテンツ配信） | 静的ファイルの高速配信・HTTPS対応 | 使った分だけ |
| SES | Simple Email Service | 遅延通知・リマインダーメール送信 | 1,000通あたり約10円 |

## 4. 技術スタック

| 区分 | 技術・サービス | 用途 |
| --- | --- | --- |
| フロントエンド | React + Tailwind CSS | 画面構築・UIコンポーネント |
| バックエンド | Node.js + Express | REST API・ビジネスロジック |
| データベース | PostgreSQL（AWS RDS） | データの永続化・管理 |
| インフラ | AWS（EC2/RDS/S3/CloudFront/SES） | クラウド環境・運用基盤 |
| 認証 | JWT（JSON Web Token） | ログイン状態の管理・セキュリティ |
| 通信 | HTTPS（REST API） | フロント↔バック間の通信 |

## 5. データフロー（処理の流れ）

例：現場監督が工程の進捗率を更新する場合

| 手順 | 処理主体 | 内容 |
| --- | --- | --- |
| ① | ユーザー操作 | スマホ画面で進捗率を「80%」に変更し、更新ボタンを押す |
| ② | フロントエンド | ReactがAPIリクエストを送信：`PATCH /api/tasks/123 { progress: 80 }` |
| ③ | CloudFront | HTTPSリクエストをEC2（バックエンド）へ転送する |
| ④ | バックエンド | JWTトークンを検証し、ログイン済みユーザーか確認（認証） |
| ⑤ | データベース | PostgreSQL（RDS）のtasksテーブルの進捗率を更新する |
| ⑥ | 通知処理 | 進捗が予定より遅れている場合、SES経由でメール通知を送信する |
| ⑦ | レスポンス | 「更新成功」をReactに返し、画面を自動更新する |

## 6. セキュリティ方針

- 通信はすべてHTTPS（CloudFrontで対応）。HTTP通信は許可しない。
- 認証にはJWTを使用。トークンの有効期限は24時間とする。
- パスワードはbcryptでハッシュ化してDBに保存する（平文保存禁止）。
- RDSはパブリックアクセスを無効化し、EC2からのみ接続を許可する（VPC内通信）。
- AWSのIAMロールで最小権限の原則を徹底する。

## 7. 非機能要件との対応

| 要件ID | 非機能要件 | アーキテクチャでの対応 |
| --- | --- | --- |
| NF-01 | 画面表示速度3秒以内 | CloudFront CDNによる静的ファイルの高速配信 |
| NF-02 | スマホ・PC両対応 | ReactのレスポンシブデザインをTailwind CSSで実現 |
| NF-03 | 暗号化・HTTPS化 | CloudFrontでHTTPS強制、bcryptでパスワード暗号化 |
| NF-04 | 稼働率99%以上 | AWS RDSのマルチAZ構成・EC2の自動復旧設定 |
